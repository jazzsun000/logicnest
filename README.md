# LogicNest

Interactive prototype of LogicNest — AI-Powered Decision Science Platform.
*Know what works. Decide what comes next.*

This is a frontend-only demo. All data is synthetic, analyses are simulated, and every estimate shown is an illustrative fixture, not a real statistical computation. No integrations are live.

Open `index.html` in any browser, or visit the deployed site.

Deployed on Vercel: https://logicnest-six.vercel.app/
